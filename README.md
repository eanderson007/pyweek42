# pyweek42
Pyweek42 entry 


HOW TO RUN CODE BASE:

- open a terminal to this unzipped project 
    * must have Python interpreter installed

- install python packages: 
    * upgrade pip first if necessary
    pip install -r requirements.txt 

- run main.py file: python -m run_game
    * NOTE: the very first time you run pygame it will take a bit to start, after that the game will startup faster


Thank you very much for playing this game!
